# Field record

One researcher kept an error ledger while directing AI coding agents through empirical work on more than a dozen
projects (2026-09-15 to 2026-10-28). The ledger's text is not released. This folder holds counts and dates only.

- ledger_entries_by_week.csv: entries per week.
- recurrence_dates.csv: the dates on which two error families were logged (a process matched by pattern; a file
  edited in place without a copy), used in the proposal and Appendix Table A2.

## The four-field protocol

One line per error found in an agent's work:

    date | what went wrong | where it should have been caught | rule now

The rule is applied in the same session and added to the agent's standing instructions. A rule that fails a second
time becomes code (a check, a screen or a tool). The protocol is the field counterpart of the audit: the ledger says
where errors arise in real projects; the audit tests, with known answers, which controls stop them.

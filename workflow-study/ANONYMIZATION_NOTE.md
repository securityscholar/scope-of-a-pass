# Anonymization and scope note

This copy was prepared from the verified original W2 release using an explicit file inventory. Originals remain unchanged. All W2 runs, conditions, saved attempts, actual experimental prompts, responses, programs, execution outputs, retrievals, scoring files and post-run audit records are retained. No scientific content was cleaned up, selectively retained, regenerated or recomputed.

## Excluded categories

- The nested earlier-study archive and its accompanying README are excluded to avoid combining distinct releases. Existing prose referring to that development history remains unchanged, so those historical comparisons cannot be fully inspected within this W2-only copy.
- The original manifest, private recovery/provenance notes, source paths and identifier mappings remain outside the reviewer directory.
- Personal correspondence, general AI conversations, unrelated work, coauthor communications, field-log entries, account/session histories, version-control history, credentials, caches and private author notes were not imported. None is needed to replace the actual experimental prompts, which are included unchanged.
- Hidden Word thumbnails, empty bibliography custom-XML stores and nonessential document properties were removed. There were no tracked changes, comments, embedded attachments or active PDF content in the inspected source documents. All document prose and visible figures are unchanged.

## Anonymized categories

- CLI session UUIDs were consistently replaced with neutral session labels. Case IDs, model labels, logical run IDs, conditions, timestamps, token counts, input hashes and scientific relationships remain intact.
- Machine-local executable, scratch and reproduction paths were replaced by neutral relative placeholders in the original source and historical documentation. No credentials were found in experimental prompts. A pagination token containing account/environment attributes was removed from one CLI plugin-catalog error; the endpoint and failure remain.
- PDF metadata/document identifiers and Word metadata/container timestamps were normalized. PDF text and rendered page pixels, Word document content and embedded study images were compared with their sources after these metadata edits. Original PNG metadata was inspected and contained only plotting-software and resolution information.
- The added historical validation JSON is explicitly an excerpt. It retains the existing W2 validation fields and excludes earlier-study fields; it is not an original complete report or newly run validation.

## Consequences and limits

The two redacted Python files remain syntactically valid source, but their neutral paths require configuration for any future execution. Original source-freeze hashes are preserved as historical evidence and no longer match the redacted adapter. The complete original reproduction driver also expects the excluded earlier-study archive. Its full original procedure cannot run unchanged from this copy, and no test, regrading, model generation or reproduction was performed to claim otherwise.

All 271 serialized request prompts are byte-identical to the source, including their experimental instruction prefix. No additional private standing instruction was found in those records. Provider/system/developer or CLI context not serialized in the release cannot be reconstructed here; complete original context is not claimed. No private reasoning text was present in the saved event files; none was synthesized. These limits constrain context-dependent explanations of agent behavior.

The existing scientific scores, the original strict-citation flags, the later citation audit and its chronology remain distinct. Account metadata redaction does not remove the observed plugin error. No unsuccessful W2 attempts, refusals, parsing errors, tool failures or deviations were selectively omitted: every stored W2 attempt and standard-error file is present.

The copy was inspected for identifying text, file and directory names, links, document properties, archive contents and binary metadata. Public research citations remain. Such inspection does not guarantee anonymity against linkage with information outside this package.
